# 中文学术改写规则

规则用于编辑，不是检测器的判定标准。不要依据某个词反推作者身份。

## 按章节调整

| 部分 | 改写重点 | 必须保留 |
|---|---|---|
| 摘要 | 明确问题、方法和主要结果，去掉重复意义陈述 | 对象、参数、数值、方向与结论范围 |
| 引言 | 建立已有进展、未解决问题与研究任务的联系 | 来源、真正的研究空缺及目标 |
| 材料与方法 | 修复歧义和累赘，保持操作可复现 | 仪器、试剂、地点、处理、重复、参数和步骤 |
| 结果 | 组织比较关系，避免机械复述表格 | 数值、单位、分组、统计判断和图表对应 |
| 讨论 | 区分本研究发现、文献和解释性推测 | 引文、反例、限制和替代解释 |
| 结论 | 保留回答研究问题的内容 | 适用范围，不增加结果、因果或外推 |

## 编辑操作

1. 删除没有增加事实或关系的套话，不连带删除观点的依据。
2. 合并重复结果，保留不同处理、时期和指标的实质差别。
3. 调整主语和句序消除歧义，不把所有被动句强制改成主动句。
4. 分清长句内的推理层次；材料只支持相关关系，就保留相关表述。
5. 同一概念使用固定术语，普通动词按上下文选择，不机械轮换。
6. 将泛化意义落实到已有具体贡献；没有内容时删除空泛评价。
7. 内容确实平行时才并列；三项真实指标无需删成两项。
8. 保留有信息价值的“可能”“在本试验条件下”“尚未发现”等限定。

不要统一所有段落长度、起始词或“结果—机制—意义”结构。
不要把语法变化解释为已掌握知网、维普、万方等平台的内部算法。

## 含义核对

| 原文关系 | 不允许产生的变化 |
|---|---|
| 土壤有机碳含量增加 | 改成储量增加、碳汇增强或长期固碳增强 |
| 正相关或变量重要性较高 | 改成驱动、决定或证明独立机制 |
| 未达到统计学差异标准 | 改成处理无效或不存在差异 |
| 相对比例提高 | 改成绝对数量增加 |
| 样点占比 | 改成区域面积占比 |
| 范围、中位数或均值 | 互换统计量名称 |
| 特定地区、时期或土层 | 外推到全国、长期或全剖面 |
| 两个模型 R² 均为负，A 较高 | 改成预测能力良好 |

土壤材料尤其核对 pH、CEC、BD、SOC、MNC、MAOC、POC、DOC、N/P/K；浓度与储量、绝对量与贡献比例、样点与制图面积不能混用。
这些举例仅在相关材料中启用，不强加给其他学科。有检验依据时保留统计判断；报告另有禁用词要求时按用户要求调整表达，不损伤含义。

## 示例：虚构教学片段，不代表降分效果

以下是完整段落示例，均按非空白字符数核对最多减少 3% 的约束。可复用的数据见 [段落示例文件](../assets/rewrite-examples.json)。不能把示例中的事实移入当前论文。

### 保留比较对象与范围

原文：本研究主要比较处理A与对照的土壤有机碳（SOC）含量。结果显示，处理A的SOC为18.6 g·kg⁻¹，对照为15.2 g·kg⁻¹，差异具有统计学意义（P＜0.05）。这一比较仅涉及本次采集的表层土壤。

可改：本研究以本次采集的表层土壤为对象，比较处理A与对照的土壤有机碳（SOC）含量。处理A的SOC为18.6 g·kg⁻¹；对照的含量为15.2 g·kg⁻¹。两者含量的差异具有统计学意义（P＜0.05）。

核对：只重组已给出的对象、范围和结果，没有增加储量、机制或应用价值。字数 100 → 98。

### 保留相关关系与限定

原文：统计结果显示，在0—20 cm土层中，SOC与黏粒含量呈正相关（r=0.62，P＜0.05）。由此可以看出，二者之间存在联系，但现有数据不能用于确定具体的作用机制。

可改：在本次分析的0—20 cm土层中，SOC与黏粒含量呈正相关，相关系数r=0.62（P＜0.05）。现有数据所显示的是两者之间的统计联系，尚不能据此确定具体的作用机制。

核对：不能改成矿物保护机制已得到验证。字数 81 → 82。

### 规范方法句可保留

原文：样品于4 ℃下保存24 h，随后测定溶解性有机碳含量。

可改：样品于4 ℃下保存24 h，随后测定溶解性有机碳含量。

核对：不凭空增加采样季节、过滤孔径或仪器型号。字数 25 → 25。

### 保留模型与统计量对应

原文：模型A和模型B的R²分别为−0.12和−0.31，RMSE分别为0.48和0.56。

可改：模型A的R²为−0.12，其RMSE为0.48；模型B的R²为−0.31，其RMSE为0.56。

核对：保留负号和对象绑定，不能改成两个模型均有较好的预测能力。字数 42 → 48。

### 原文含无依据评价时

例如原段另有“这一结果充分证明处理A具有重要的应用价值”，但没有相关材料支持，应将原句和疑点留在批注或核实清单中，不纳入净稿。删除后重新核对该段字数；不能在不添事实的前提下满足 3% 约束时，报告实际冲突，不能用无依据的替代结论凑数。

## 人工判断

逐段回答：该段说了什么？凭什么这样说？与上下文怎样衔接？改写后这三个答案是否改变？
必须补出处才能成立的内容列为作者待核实事项，保留有依据的其余正文。
