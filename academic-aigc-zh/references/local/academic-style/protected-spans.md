# 受保护片段与对应关系

本模块基于上游内容修改适配，来源及修改记录见 [来源清单](../../resource-manifest.json)。模块附注见 [NOTICE](NOTICE)。版本与改动记录见 [本地清单](../../resource-manifest.json)。无需访问原项目。

## 改写前固定什么

| 内容 | 记录方式 | 修改边界 |
|---|---|---|
| 数值与统计量 | 连同处理、指标、时期、土层和比较基准记录 | 保留负号、小数精度、单位、区间、P 值方向；不能只核数字集合 |
| 引文 | 原句主张与引用标记配对 | 移动句子时保持配对，不新增编号或把别处引文移来背书 |
| 专业术语 | 对象、变量、缩写与全称对照 | 同一概念保持同一名称，不为换词混淆不同概念 |
| 图、表、公式 | 标记和对应对象一并定位 | 不改变编号、变量、运算符、单位、域或交叉引用 |
| 直接引语 | 记录精确文本及其原位置 | 引语内容不做一般改写；外围叙述可按原义调整 |
| 方法与条件 | 材料、步骤、参数和适用条件 | 规范方法句可以不改；不能添入未给出的仪器、季节、重复数 |

## 关系核对

先把原段转换为内部记录：`对象—指标—数值—比较对象—方向—限定—引文`。改后用相同字段重新提取，再逐项比较。字段只供编辑核对，不加入论文正文。

- “A 和 B 分别为……”改为分句时，按原对应关系逐个展开。数字总数相同也可能发生错配。
- 相关关系、变量重要性和解释性推测不能改成已经验证的因果或机制。
- “可能”“在本研究条件下”“尚不能确定”各自限定不同层次，不能以“一句只留一个限定词”为由删除。
- “差异具有统计学意义”有检验支持时保留；“具有应用价值”需要单独依据。
- 名称内、引号内和技术用法中的普通提示词，不按风格词表机械替换。

土壤稿另核浓度与储量、绝对量与比例、样点与面积、表层与全剖面。其他学科按其实际指标建立对应关系。

## 格式也属于受保护对象

在 Word 原文件的副本中改写指定文本，保留原有段落属性和运行属性。方法、公式、图表、脚注、文献域、页眉页脚及未编辑部件保留。英文和数字沿用原来的字体；用户要求 Times New Roman 时，对需新增或明确授权修改的英文和数字设置该字体，不据此统一重排全文。

脚本 `scripts/check_revision.py` 能标记部分文本变化，不能替代对象绑定和语义核对。原文疑点保存到批注或作者核实清单；净稿不夹带编辑说明，不擅改数据。
