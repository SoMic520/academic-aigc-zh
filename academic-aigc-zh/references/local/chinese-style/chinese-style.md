# 中文表达的局部检查

本模块基于上游内容修改适配，来源及修改记录见 [来源清单](../../resource-manifest.json)。模块附注见 [NOTICE](NOTICE)。此处只保留适合正式学术文稿的编辑操作。

## 处理与保留

| 表达类型 | 使用本地规则的方式 |
|---|---|
| 宣传式意义或泛化展望 | 核对是否有已提供的结果、文献或真实研究计划支撑；缺依据时不编造替代内容 |
| 模糊归因 | 检查同句及相邻上下文中的引文归属；不能为显得具体而凭空添加作者、年份或样本 |
| 堆叠修饰与引导语 | 只合并重复含义，保留限制研究条件、效应大小或确定性的不同成分 |
| 复杂的系动词表达 | 只有含义等价时改为“是、有”；不能把关联、代表关系或局部作用都改成定义 |
| 重复否定式对照 | 两边承载真实区别时保留，例如“浓度提高不等于储量增加” |
| 同义词循环 | 恢复原文的概念边界，统一同一术语，不混用不同概念 |
| 真实三项并列 | 完整保留；仅调整冗余的句法外壳 |
| 聊天残留 | 从论文中去掉“希望对您有帮助”等对话包装，保留其后的实质正文 |

## 中文与文档格式

中文引号、标点和专业复合词按原文及规范使用。引号形态、单个连接词、三项列举或句长本身不能判定作者身份。

不把通用文案的格式清理规则应用到原 Word：标题、加粗、字体、编号和表格样式保持原样。原文中的直接引语、研究对象用语和术语即使命中词表，也不自动删除。

## 可执行辅助

运行本地 `scripts/scan_style.py` 后逐条阅读其命中文本和上下文。每条提示都需要人工判断：确有问题才改；合法的术语、真实引用和必要逻辑继续保留。检查器只提出编辑提示，不自动替换、不打分、不修改原稿。

使用完整段落重组满足篇幅约束。不要用通用文案的“大幅精简”目标处理论文，也不要用自评“已去除 AI 痕迹”代替检测结果。
