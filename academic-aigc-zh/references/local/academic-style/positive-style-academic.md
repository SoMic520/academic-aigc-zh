# 中文论文的书面表达

本模块基于上游内容修改适配，来源及修改记录见 [来源清单](../../../third_party/manifest.json)。许可见 [LICENSE](../../../third_party/academic-style/LICENSE)。规则用于编辑判断，不用于预测检测结果。

## 具体操作

1. 先识别段落已有的对象、比较和限定，再选择主句。让主句直接承担论点或结果，不先宣告“深入分析”“全面揭示”。
2. 冗余引导语可删，但其后的事实、引文和限定继续保留。需要维持篇幅时，把原有的压缩比较完整展开，不能添数据、机制或意义。
3. 长句按实际语义边界拆分；短句若割裂条件与结果，则重新合并。不设句长、破折号或主动语态配额。
4. 保留材料与方法中自然的被动表达。明确操作对象比强行补一个“我们”更重要。
5. 对相同术语保持一致；只有原文确实区分的概念才用不同名称。
6. 原文已有具体贡献时把贡献写清楚。原文只有泛化评价时，不能用臆造的数字、后续计划或实验细节把评价“具体化”。

## 条件判断表

| 发现的表达 | 先问什么 | 可采取的处理 |
|---|---|---|
| “本研究充分证明……” | 研究设计是否支持这种确定性？ | 按已有检验和限定恢复原主张的强度；疑点另列 |
| 多层“从而、进而、由此” | 每一层因果是否有独立依据？ | 区分观察和推断；保留有依据的联系 |
| 段尾重复结果 | 是否包含新范围或新限定？ | 合并重复部分，同时保留独有信息 |
| 三项平行内容 | 是真实的三项指标还是空泛排列？ | 真实项目全部保留；不强制改成两项或四项 |
| “相关研究表明” | 同句、前句或段落是否已有对应引文？ | 有依据则保留或明确指代；缺失则批注核实 |
| 多个相似段首 | 是否承担不同章节功能？ | 仅修复实际重复，不移动必须先定义的理论或变量 |

## 语体检查

完整改稿应保持正式、清楚、克制。不得为了显得自然而增加聊天语、反问、作者感受、失败经历、故意错误或无关插话。用户提供旧稿时，只借其句法和语气，不借其事实。

对比示例只从 [完整段落示例](../../rewrite-rules.md) 使用。不要把上游示例中额外出现的年份、样本、数值和机制带入当前稿件。每段及全文默认至少保留原有非空白字符数的 97%，优先展开已有信息，确有事实与篇幅冲突时单列说明。
