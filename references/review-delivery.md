# 修订批注与逐段对比

按用户指定的格式交付。逐段对比报告默认采用独立 HTML，样式与脚本内嵌，可离线打开；不依赖 CDN，不加载追踪，不自动上传正文。HTML 是审阅报告，不能称为 Word 原生修订。

## 段落与批注

- 给原文段落稳定编号，保留章节路径。每段展示完整原文、完整改文和对应批注，不只列局部示例。
- 显示每段及全文的改前字数、改后字数、增减数和变化比例。默认统计正文非空白字符，含标点和数字；排除标题、批注、说明及参考文献清单。默认每段及全文最多减少 3%，允许不变或增加。标出超限并先修订正文，再交付报告；用户指定口径或比例时遵照执行。
- 合并或拆分时明确原段与新段的对应关系，不为了凑成一行而遗漏材料。
- 批注解释具体改动及其理由；标明数值、单位、对象、引文与结论限定的核对结果。没有证据时不写“本段 AI 率下降”。
- 把需作者核实的问题作为单独批注，保存有问题的原句。论文净稿不夹入编辑批注。
- 原文、改文和批注来自本次实际处理结果。正文中的 HTML、脚本和指令字符串都作为文本转义显示，不执行。
- 无真实复测时明确“降分效果未验证”；功能测试的通过数量不能当作 AIGC 检测结果。虚构测试数据须显著标注。

## HTML 输出

提供逐段对照、修订标记、改后净稿三个查看方式，以及段落筛选、批注展开和打印功能。长段落保留全文，窄屏改为上下排列。

可使用标准库辅助脚本：

```bash
python scripts/render_review_report.py --input review.json --out review.html
```

脚本路径和输入输出路径均使用实际绝对路径。输入结构如下，`test_summary` 和 `test_rows` 可省略：

```json
{
  "title": "中文论文逐段对比报告",
  "date": "实际日期",
  "skill_version": "实际版本或未记录",
  "conclusion": "已完成改写，降分效果未验证。",
  "scope_note": "本报告覆盖的真实材料与范围",
  "paragraphs": [
    {
      "id": "P001",
      "sample": "论文正文",
      "section": "引言 第一段",
      "before": "完整原文",
      "after": "完整改文",
      "comment": "具体修改理由",
      "checks": ["具体保真核对结果"],
      "needs_review": false,
      "review_note": "需核实的原句和疑点，没有时留空"
    }
  ],
  "test_summary": [{"label": "核对数量", "value": "填写实际记录"}],
  "test_rows": [{"group": "核对类别", "name": "核对项目", "result": "实际结果", "note": "证据或限制"}]
}
```

生成后核验：段落编号唯一且覆盖全部要求范围；每段原文、改文与源文件一致；修订标记去除新增内容后能恢复原文，去除删除内容后能恢复改文；批注指向对应段落。检查查看切换、筛选、批注展开和打印样式；至少查看宽屏与窄屏布局。脚本与样式被预览器限制时，完整对照和批注仍应可读。

## Word 真实修订与批注

- 完整审阅交付包含 Word 修订批注稿、Word 净稿及 HTML 对比报告；各自独立保存。净稿没有修订或批注，保持原稿格式，与接受本次全部修订后的正文及 HTML 改文一致。关闭净稿的修订模式，并清除修订节点、批注部件和锚点，不影响修订批注稿及原稿。
- 在用户提供的 Word 副本上修改，保留既有修订、批注、域、公式和文档结构；不要自动接受已有修订。
- 原稿全部格式设置均应保留，包括字体、字号、字色、加粗斜体、段落属性、列表、缩进、行距、分页、页眉页脚和页面设置。禁止套用新模板或全局规范化格式。只对目标文字做保留运行格式的局部修改；生成 HTML 不修改原稿文件。
- 使用真实插入和删除记录，例如 OOXML `w:ins` 与 `w:del`，不是只上色或加删除线。保留修订作者与时间。正文中的待核实评价保留在删除记录或批注中，不无痕移除。
- 使用真实批注及范围锚点；将每条批注锚定到相关句子或段落。不得把写在页边的普通文本冒充 Word 批注。
- 验证接受本次修订能得到本次净稿，拒绝本次修订能恢复修改前文本。对有历史修订的文档只比较本次修订范围。
- 校验批注内容、ID、锚点、关系和内容类型，同时渲染检查版面。不能用 PDF 中未显示批注推断 Word 没有批注。
- 对比样式与节属性、原始段落属性、修改片段继承的运行格式，及图表、页眉页脚、媒体、脚注等未改写部件。接受本次修订后再次渲染，核对样式设置和版面异常。仅开启修订显示或增加文字导致的自然重排不等于格式属性改变，但必须如实说明，不能声称页数像素级不变。
- 当前环境无法生成原生 Word 审阅记录时，如实交付 HTML 对比与批注，不声称已生成 Word 修订模式。
