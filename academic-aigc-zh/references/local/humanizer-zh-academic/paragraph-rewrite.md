# 逐段组织中文学术论述

本文件由本地下载的 humanizer-zh-academic 的 SKILL.md 修改整理。许可见 [LICENSE](../../../third_party/humanizer-zh-academic/LICENSE)。本模块直接用于改写，不要求先出识别报告再等用户确认。

## 每段执行顺序

1. 识别段落功能、原有信息和上下文关系，保存段落 ID 与原文非空白字符数。
2. 写出该段要回答的问题，但不要把这条内部问题机械地放在段首。
3. 选择材料支持的展开顺序：对象与比较、问题与方法、观察与限定、已有解释与本研究发现。无需全篇统一排序。
4. 重组主语、宾语、条件从句及句间衔接，去掉重复的宣告语。真实步骤和真实并列项保持完整。
5. 回查原文中的每条事实、依据和限定，再检查各段及正文合计的字数约束。

## 结构优化的边界

| 常见情况 | 合理调整 | 不能这样调整 |
|---|---|---|
| 每段都用理论开头 | 原文已有现象时，可将现象先行并保持理论解释关系 | 编造课堂观察、访谈或试验过程；把必须先定义的理论后移 |
| 每段都以意义收尾 | 保留真正结论，合并无新增信息的重复总结 | 删掉有效贡献，另造研究计划补字 |
| 固定“首先、其次、再次” | 根据材料中的顺序、并列或轻重关系重组句子 | 任意宣称某一项最重要，漏掉真实项目 |
| 抽象问题宣告 | 把原文已有对象和条件放进主句 | 增添国家、地点、量表、样本或反问情境 |
| 反复“体现了、揭示了” | 说清已有观察与已有判断的对应关系 | 因避词而降低有依据的结论，或把相关改成因果 |
| 研究者视角不足 | 使用原文有依据的研究选择与解释 | 填入“出乎意料”“多次失败后”等未经提供的经历 |

## 维持篇幅

默认每个映射段落组和正文合计都满足 `改后非空白字符数 >= 原文非空白字符数 × 0.97`。计算用精确整数比较：`改后 × 100 >= 原文 × 97`，不能靠四舍五入判定通过。

- 优先保留原文中容易漏掉的对照对象、条件、比较方向、方法步骤和范围。
- 将原来用“分别”“相应”压缩的信息完整展开，适度补全原有省略成分。
- 拆句不等于删内容；全文增长也不能抵消某一段超过 3% 的缩减。
- 不把批注、标题、报告文字或重复空话计入正文凑数。
- 保留 Word 原格式时默认不合并、拆分原段落；确需改变段落结构须先有用户授权。纯文本允许合理调整，但要建立段落组映射。

如果删除缺乏依据的原句后，无法在不添事实的前提下满足篇幅，保留其原句和准确差额在批注或核实清单，继续交付可成立的正文。不得声称字数检查全部通过。
